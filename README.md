## ❓ FAQ

### Does MSFS Cheat add unlimited credits to Career Mode?

No. Standard Career Mode credits are stored in account cloud data and cannot be edited through a supported local cheat.

### Is Developer Mode available to every player?

Developer Mode provides built-in development tools, but some advanced testing features require registered Microsoft-partner access.

### Can I use it on Windows 11?

The reference package is intended for Windows 10 and Windows 11 systems. Simulator requirements still apply.

### Does the Career Tool unlock every mission?

The developer testing profile can load a separate save with unlocked certifications, companies, missions, and a large credit balance. Access is restricted to registered Microsoft partners.

### Can I install aircraft and scenery add-ons?

Yes. MSFS 2024 supports add-on packages. The simulator uses separate Community folders for MSFS 2020 and MSFS 2024 content.
